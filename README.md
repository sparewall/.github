# sparewall/.github

Organization-wide files for [Sparewall](https://github.com/sparewall):

- `profile/README.md` — the organization profile page
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` — community health
  files that GitHub applies to every repository in the organization without
  its own copy
- `.github/workflows/` — reusable workflows shared by Sparewall repositories
