# Security policy

Sparewall is a firewall, so we take security reports seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/sparewall/sparewall/security/advisories/new)
on the affected repository. Do not open a public issue.

Include the affected version or image digest, a description of the issue,
and steps to reproduce if you have them. We aim to acknowledge reports
within a week.

## Supported versions

Sparewall has not reached 1.0. Until then, only the latest image on the
`stable` channel (and the `main` branch) receives fixes.
